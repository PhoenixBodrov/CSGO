# CS:GO

The CS:GO part of [Game and Feel](https://github.com/users/PhoenixBodrov/projects/1).

Use the shared project board for plans and progress. [Minecraft](https://github.com/PhoenixBodrov/Minecraft) has its own repository with Minecraft 1.21 NeoForge and Minecraft 1.20.1 Forge folders.

## Development

The pack files have not been imported yet. Add verified configs, scripts, manifests and original assets when the source folder is available. Document required game and mod versions before making a release.

Work on a separate branch for each task and review changes through pull requests. Record what was tested and link each fix to its issue.

## Ideas and testing

[Create an issue](https://github.com/PhoenixBodrov/CSGO/issues/new/choose) for a feature idea, task, bug or playtest report. Anyone with a GitHub account can post and comment. Search existing bugs and add new findings to the matching issue.

Include the pack version or commit, reproduction steps, expected and actual results, and relevant screenshots or log excerpts. Remove private information from evidence before posting.
